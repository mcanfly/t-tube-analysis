This shows a sample image processing strategy in Matlab 2023b for cardiac t-tubules following the method described in 
Soeller C, Cannell MB. (1999) Circulation research. 84:266-275. 
It is supporting material for "Using confocal microscopy and image processing to measure properties of 
sub-resolution cell structures: Application to cardiac transverse tubules"
Authored by Mark B. Cannell and Cherrie H.T. Kong in J.Micoscopy 2026
